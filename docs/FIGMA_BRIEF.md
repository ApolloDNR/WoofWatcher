# WoofWatcher v1.5 Figma Brief

Date: 2026-06-12

## Brief

Design WoofWatcher as Premium Neo-Retro Pixel Care: professional dog-care software with a playful pixel-pet heart.

The design must feel trustworthy for health, records, medications, sitters, trainers, and vets, while still making Phoenix feel alive inside the app.

## Brand System

- Name: WoofWatcher
- Core line: Real care. Pixel heart.
- Tagline: Your dog's day, brought to life.
- Visual style: Premium Neo-Retro Pixel Care.

## Typography

- Main UI: Inter, Nunito Sans, or system-ui.
- Pixel accent font only for logo, badges, speech bubbles, XP/level/status labels, or small decorative elements.
- Do not use pixel font for long content.
